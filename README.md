# 🎨 Wikimedia 25th Anniversary – Design Assets

## 📌 About the Project

This repository contains creative design assets and visual elements prepared for Wikimedia-related activities and the Wikipedia 25th Anniversary theme. It includes graphics, illustrations, social media designs, icons, and other visual resources created to support digital communication and community engagement.

The designs follow a blue-and-white visual theme inspired by Wikimedia's branding and the Wikipedia community.

## ✨ Project Highlights

- 🎨 Creative graphic design assets
- 🧩 Wikipedia-themed puzzle illustrations
- 🌐 Wikimedia-inspired icons and graphics
- 📱 Social media cover designs
- 🎂 Wikipedia 25th Anniversary visuals
- 🤝 Diversity and community-related illustrations
- 🖱️ Custom cursor and thumbs-up graphics

## 🛠️ Tools & Technologies

## 🎯 Project Objective

The objective of this project is to create visually appealing and consistent design resources for Wikimedia-related initiatives, helping communicate community activities, celebrate Wikipedia's milestone, and promote engagement through digital graphics.
